## 📚 Introduzione

<a href="https://hi.events">Hi.Events</a> è una piattaforma completa, self-hosted, per la gestione di eventi e la vendita di biglietti online, pensata per tutti i tipi di eventi. Dai convegni e workshop alle serate in discoteca e ai concerti, Hi.Events ti offre tutto ciò di cui hai bisogno per creare, gestire e monetizzare i tuoi eventi con facilità.

## 🌟 Key Features

<a href="https://hi.events">Hi.Events</a> offre strumenti completi per semplificare la gestione dei tuoi eventi:

### 🎟 Biglietteria e Vendita Prodotti
- **Tipi di Biglietti Multipli:** Gratuito, a pagamento, a donazione e a livelli.  
- **Gestione della Capienza:** Imposta limiti generali per l’evento o specifici per ogni biglietto.  
- **Assegnazioni di Capienza:** Gestisci una capienza condivisa tra diversi tipi di biglietti.  
- **Codici Promozionali:** Codici sconto per accesso in prevendita e offerte speciali.  
- **Vendita di Prodotti:** Vendi prodotti legati all’evento (es. magliette, extra).  
- **Tasse e Commissioni:** Applica tasse e commissioni personalizzate per prodotto o ordine.

### 🏆 Gestione Eventi e Personalizzazione
- **Dashboard Evento:** Analisi in tempo reale di entrate, vendite di biglietti e partecipanti.  
- **Editor Homepage:** Personalizza le pagine evento con un editor a anteprima live.  
- **Widget Biglietti Integrabile:** Offri un'esperienza di acquisto fluida direttamente sul tuo sito.  
- **Strumenti SEO:** Personalizza i metadati degli eventi per una migliore visibilità nei motori di ricerca.  
- **Categorie Prodotti:** Organizza biglietti e prodotti tramite la gestione delle categorie.  
- **Supporto per Eventi Offline:** Fornisci istruzioni dettagliate per eventi fisici.

### 📧 Partecipanti & Gestione Ordini
- **Moduli di Checkout Personalizzati:** Raccogli informazioni dai partecipanti con domande su misura.  
- **Gestione dei Partecipanti:** Cerca, modifica, cancella e invia messaggi ai partecipanti.  
- **Gestione degli Ordini:** Rimborsa, annulla e reinvia i dettagli degli ordini con facilità.  
- **Messaggistica di Massa:** Invia email o messaggi a determinati possessori di biglietto.  
- **Esportazione Dati:** Esporta partecipanti e ordini in formato CSV/XLSX.

### 📱 Compatibile con Dispositivi Mobili & Strumenti di Check-In  
- **Check-In con QR Code:** Strumento di check-in basato sul web e ottimizzato per dispositivi mobili.  
- **Liste di Check-In:** Genera e condividi liste di accesso controllato per il check-in.  
- **Accesso Multi-Utente:** Controllo degli accessi basato sui ruoli per lo staff dell’evento.

### 🔧 Integrazioni e Automazione  
- **Supporto Webhook:** Automatizza le attività con Zapier, IFTTT, Make o integrazioni con CRM.  
- **Integrazione con Stripe Connect:** Gli organizzatori ricevono pagamenti immediati.

### 📊 Funzionalità Avanzate  
- **Supporto Multilingua:** Inglese, Tedesco, Spagnolo, Portoghese, Francese, Cinese (中文 Zhōngwén), Italiano e altro ancora.  
- **Rimborsi Parziali e Totali:** Gestisci i rimborsi con tracciamento dettagliato degli ordini.  
- **Controllo Accessi Basato sui Ruoli:** Più ruoli utente con gestione dei permessi.  
- **API REST:** Accesso completo all’API per integrazioni personalizzate.  
- **Sistema di Fatturazione:** Genera e invia fatture con dettagli fiscali, termini di pagamento e scadenze.  
- **Supporto ai Pagamenti Offline:** Abilita bonifici bancari, pagamenti in contanti o metodi personalizzati.  
- **Archivio Eventi:** Archivia eventi passati per mantenere il dashboard ordinato.  
- **Blocco Avanzato dei Biglietti:** Proteggi biglietti con codici promo o restrizioni di accesso.  
- **Reportistica Avanzata:** Report giornalieri di vendita, dettagli fiscali, vendite di prodotti e uso dei codici promozionali.

## 🚀 Get started

### 🐳 Avvio Rapido con Docker

> [!IMPORTANTE]  
> Assicurati di avere Docker e Docker Compose installati sul tuo sistema. In caso contrario, puoi scaricarli dal sito ufficiale: [Docker](https://www.docker.com/get-started).

1. **Clona il Repository:**  
   ```bash
   git clone git@github.com:HiEventsDev/hi.events.git
   ```

2. **Naviga nella Directory Docker:**  
   ```bash
   cd hi.events/docker/all-in-one
   ```

3. **Genera `APP_KEY` e `JWT_SECRET`**

   Usa i seguenti comandi per generare le chiavi:

   **Unix/Linux/MacOS:**  
   ```bash
   echo base64:$(openssl rand -base64 32)  # Per APP_KEY  
   openssl rand -base64 32                 # Per JWT_SECRET  
   ```

   **Windows:**  
   Consulta le istruzioni nel file *./docker/all-in-one/README.md* per generare le chiavi su Windows.

   Aggiungi i valori generati al file `.env` che si trova in `./docker/all-in-one/.env`

4. **Avvia i Container Docker:**  
   ```bash
   docker compose up -d
   ```

5. **Crea un account:**  
   Apri il browser e vai su:  
   [http://localhost:8123/auth/register](http://localhost:8123/auth/register)

ℹ️ Per istruzioni dettagliate sull’installazione, incluso il deploy in produzione, consulta la nostra [guida introduttiva](https://hi.events/docs/getting-started) (in inglese).
